ChoreQuest starter prototype

Files: index.html, manifest.webmanifest, icon.svg, sw.js

Test on a computer: double-click index.html. Chores and coins save in your browser.
To install on a phone, deploy these four files to HTTPS hosting such as Cloudflare Pages.

IMPORTANT: This is a single-device prototype. There is NO account login, shared database, automatic rotation, or household syncing yet. Do not use it as a real multi-user household system until those features are built and tested.
